Gmail
  1. Gear icon → See all settings → scroll to Signature.
  2. + Create new, name it, click into the box.
  3. Paste with Ctrl + V (Mac: Cmd + V). Never Ctrl + Shift + V — it strips the formatting.
  4. Set both Signature defaults dropdowns to the new signature.
  5. Scroll down, Save Changes, send a test email to robin@anythingsupplies.com.
Outlook
  1. File → Options → Mail → Signatures (new Outlook / web: Settings → Mail → Compose and reply).
  2. New, name it, click into the edit box.
  3. Paste with Ctrl + V. Never Ctrl + Shift + V.
  4. Set New messages and Replies/forwards to the new signature.
  5. OK, then send a test email to robin@anythingsupplies.com.
